# Technical descisions

All the types should immutable. Any action that should return a modified instance of a type should return a new instance instead.

# Types

## Step

Represents the musical steps A, B, C, D, E, F, G in terms of semitone distances from C (where C is 0). This enum encapsulates these steps as values used in music theory.

```csharp
public enum Step
{
    C = 0,
    D = 2,
    E = 4,
    F = 5,
    G = 7,
    A = 9,
    B = 11,
}
```

## Accidental

Represents the common accidentals used in music theory: **flat** (b), **sharp** (#), **double flat** (bb), and **double sharp** (##). This class encapsulates the accidental and its symbolic representation.

```csharp
public class Accidental
{
	public int Alter { get; }
    public string Symbol { get; }
}
```

### Possible values

| **Alter** | **Symbol** | **Description**                |
|-----------------|------------|--------------------------------|
| -2              | `bb`       | Double Flat                    |
| -1              | `b`        | Flat                           |
| 0               |  ``        | Natural (No Accidental)        |
| 1               | `#`        | Sharp                          |
| 2               | `##`       | Double Sharp                   |


## Octave

Represents an octave in terms of both its **name** and **number**, as well as its **scientific pitch** notation. This class allows us to map the octave’s name and number, and understand its relation to pitch in a musical context.

```csharp
public class Octave
{
	public int Number { get; }
	public string Name { get; }
	public string ScientificPitch { get; }
}
```

### Possible values

|Octave Name|Scientific Pitch|Octave Number|
|---|---|---|
|Subcontra|C0|–1|
|Contra|C1|0|
|Great|C2|1|
|Small|C3|2|
|One-lined|C4|3|
|Two-lined|C5|4|
|Three-lined|C6|5|
|Four-lined|C7|6|
|Five-lined|C8|7|
|Six-lined|C9|8|

## PitchClass

Represents a combination of **Step** (A, B, C, etc.) and an **Accidental** (sharp, flat, etc.). A **PitchClass** refers to a note's identity without a specific octave.

```csharp
public class PitchClass
{
    public Step Step { get; }
    public Accidental Accidental { get; }
}
```

## Note

A **Note** is a **PitchClass** combined with an **Octave**, creating a specific pitch that exists in time. This is a concrete representation of a note in music.

```csharp
public class Note
{
    public Pitch Pitch { get; }
    public Octave Octave { get; }
}
```

## ChordFormula

A **ChordFormula** represents the formula or the set of **intervals** used to construct a chord, relative to a root. It defines how the chord is built using **Pitch** classes (such as root, lead, and other notes). This formula does not assign specific octaves.

```csharp
public class ChordFormula
{
    public IReadOnlyList<Pitch> Pitches { get; }
    public Pitch Root { get; }
```

## Chord

A **Chord** is a concrete realization of a chord formula, specifying **Notes** in specific **Octaves**. This type allows you to specify the notes that make up a chord, including its root, lead, and inversion.


## IntervalQuality

Describes the **quality** of an interval (such as Perfect, Major, Minor, Augmented, or Diminished).

```csharp
public enum IntervalQuality
{
    Perfect,
    Major,
    Minor,
    Augmented,
    Diminished
}
```

## IntervalQuantity

Describes the **quantity** of an interval (such as Unison, Second, Third, etc.). This is the distance between two notes in terms of scale steps.

```csharp
public enum IntervalName
{
    Unison,
    Second,
    Third,
    Fourth,
    Fifth,
    Sixth,
    Seventh,
    Octave,
    Ninth,
    Tenth,
    Eleventh,
    Twelfth,
    Thirteenth,
    Fourteenth,
    Fifteenth
}
```

## Interval

An **Interval** describes the relationship between two notes in terms of both **quality** and **quantity**. The **DistanceInSemitones** property indicates the number of semitones between the two notes, which can be useful for transposition operations.

```csharp
public class Interval
{
    public IntervalQuality Quality { get; }
    public IntervalQuantity Quantity { get; }
    public int DistanceInSemitones { get; }
}
```

## ScaleFormula

A **ScaleFormula** is a series of **Intervals** that defines the structure of a scale. This is used to build specific scales (e.g., major, minor, pentatonic) based on predefined interval relationships.

```csharp
public class ScaleFormula
{
    public IReadOnlyList<Interval> Intervals { get; }
    public string Name { get; }
}
```

## Scale

A **Scale** is a concrete realization of a **ScaleFormula**, containing the specific **Pitch** instances that form the scale. This allows for operations with the actual notes of a scale, including transposition and transformation.

```csharp
public class Scale
{
    public ScaleFormula Formula { get; }
    public IReadOnlyList<Pitch> Pitches { get; }
}
```
